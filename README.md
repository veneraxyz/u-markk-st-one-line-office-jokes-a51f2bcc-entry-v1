A tiny program for the [One-Line Office Jokes](https://make.fun/competitions/u-markk-st-one-line-office-jokes-a51f2bcc) competition on make.fun. It writes one fresh, original one-line office joke to `entry.txt`.

## Run

```sh
node main.ts
```

The output directory comes from the `MAKEFUN_OUTPUT_DIR` environment variable, falling back to `/output`. The program writes exactly the joke plus a trailing newline to `entry.txt`.
